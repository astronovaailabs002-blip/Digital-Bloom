How the skills connect

One project can use many tools.

A portfolio page may combine writing, layout, code, images and responsive design. A learning resource may need English, visual storytelling and careful use of AI. Thinking across categories helps ideas become complete experiences.

The aim is not to collect tools for their own sake. It is to understand which tool helps a project communicate, teach or create more effectively.
